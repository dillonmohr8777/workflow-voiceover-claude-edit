### 01:30 — The recommended starting setup

- Download the ChatGPT desktop app first.
- Tell the AI the person’s role and normal day-to-day responsibilities.
- Ask the AI which integrations would help that role.
- Provide context over time so the system can learn how the person works.
- Use Plan Mode when a task benefits from an explicit plan.
- Selecting a formal project is optional for many ordinary tasks.
- Workflows should be divided by organizational role.
- Each workflow should be personalized while remaining simple enough to adopt.

## Recommended follow-up checklist implied by the video

1. Install the ChatGPT desktop app.
2. Tell ChatGPT or Codex your role, responsibilities, recurring tasks, and preferred communication style.
3. Ask it to identify the smallest set of integrations needed for that role.
4. Connect only approved services, starting with Gmail and Slack where appropriate.
5. Add role-specific tools such as HubSpot, Canva, Figma, Chrome, Google Sheets, Ads platforms, Semrush, or Google Keyword Planner.
6. Use Plan Mode to turn current responsibilities into repeatable daily workflows.
7. Keep each workflow simple, role-specific, and easy to adopt.
8. Personalize email tone and signatures before using AI for client communication.
9. Review every client-facing message before sending.
10. Protect client information and keep control over browser and computer-use actions.
